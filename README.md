# AI-Based Fall Detection and Emergency Response System for Elderly Care

**Capstone Project | SDG 3 – Good Health and Well-being**

## Project Overview
This project detects falls of elderly people using accelerometer and gyroscope data and sends real-time alerts to caregivers.

## Dataset
We are using the **SisFall Dataset**.  
Download it from: [Kaggle - SisFall Dataset](https://www.kaggle.com/datasets/thevman/sisfall-dataset)

After downloading, extract and place the folder inside the `data/` directory.
